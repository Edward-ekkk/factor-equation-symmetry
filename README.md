# Factor Equation Symmetry Theorem and Its Applications

By Meng Qinghua

[Read the full book online (PDF)](https://edward-ekkk.github.io/factor-equation-symmetry/Factor%20Equation.pdf)

## Abstract

This book develops a factor-based approach to algebraic equations. It defines factor equations, classifies them by degree and solution type, and introduces the Factor Symmetry Theorems. It presents a method for finding rational roots of univariate polynomials and studies the equation x<sup>n</sup> + y<sup>n</sup> = z<sup>n</sup>, beginning with the cases n = 2 and n = 3 before presenting a formula for real solutions. The book also discusses Pythagorean triples, rational solutions of the right-triangle equation, and the author’s proposed arguments concerning Fermat’s Last Theorem.
